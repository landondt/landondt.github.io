# Landon's Little Corner of the Web

A static personal website made with HTML, CSS, and JavaScript.

## Publish with GitHub Pages

Upload the contents of this folder to the root of your public `USERNAME.github.io` repository. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/(root)`.

## Site files

- `index.html` — homepage
- `poetry.html` — poetry archive
- `photography.html` — photo album
- `styles.css` — styling
- `script.js` — browser-local visitor counter
- `assets/` — icon, under-construction badge, and photo folder

The poetry and photography pages currently use understated archive notes and empty frames rather than editor instructions. To publish real work later, add it to the relevant HTML page and upload your photos to `assets/photos/`.
