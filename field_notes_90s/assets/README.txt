ASSETS FOLDER

icons/moth.svg = the little moth icon used as the browser tab icon and homepage decoration.
buttons/under-construction.svg = the retro under-construction badge.
photos/ = put your own JPG, PNG, or WebP photos here, then reference them in photography.html, for example:
<img src="assets/photos/my-photo.jpg" alt="A sunset over the water">

GitHub only keeps folders that contain files, so these starter files make the folders visible in the repository.
