A tiny gallery of places, objects, and moments that caught my eye. Add your own photos to assets/photos/ and then replace these sample panels with image tags.

Please only upload photographs you have permission to share.

How to add a photo

  1. Open the repository on GitHub.
  2. Open assets, then photos.
  3. Choose Add file → Upload files and upload a JPG or PNG.
  4. In this page's HTML, replace a colored placeholder with an image like this:
    <img src="assets/photos/my-photo.jpg" alt="A short description">
